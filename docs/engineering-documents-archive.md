# آرشیو مستندات مهندسی

این ماژول برای نگهداری نسخه‌بندی‌شده مستندات مهندسی و نمایش فقط آخرین نسخه فعال هر سند طراحی شده است.

## نگهداری فایل‌های اصلی PDF در دیتابیس

فایل اصلی هر نسخه در ستون `PdfContent` از نوع `varbinary(max)` در جدول `EngineeringDocumentVersions` ذخیره می‌شود. هش SHA-256 هر فایل نیز در ستون `Sha256` نگهداری می‌شود. هیچ فایل PDF دائمی یا موقت روی دیسک سرور ذخیره نمی‌شود.

## تبدیل PDF به تصویر

هنگام مشاهده، برنامه محتوای PDF را مستقیماً از SQL Server در حافظه می‌خواند و با کتابخانه PDFium (بسته NuGet از طریق PDFtoImage) صفحه‌ها را به تصویر تبدیل می‌کند. نصب Poppler، وجود فایل `pdftoppm.exe`، تنظیم PATH یا مقداردهی `EngineeringDocuments:PdfToPpmPath` لازم نیست.

تصاویر PNG پس از اعمال واترمارک نام و شناسه کاربر در مسیر موقت خصوصی `App_Data/EngineeringDocumentTemp` ذخیره می‌شوند. تصاویر هنگام بستن نمایشگر حذف می‌شوند و پاکسازی دوره‌ای نیز فایل‌های باقی‌مانده را حداکثر پس از چهار ساعت حذف می‌کند.

حساب Application Pool فقط برای پوشه `App_Data/EngineeringDocumentTemp` به مجوز Read/Write نیاز دارد. پوشه موقت نباید از Static Files یا مسیر عمومی وب‌سایت سرو شود. فایل اصلی PDF هیچ‌گاه در این پوشه قرار نمی‌گیرد.

## حدود و ملاحظات امنیتی

نمایشگر، فایل اصلی PDF را در مرورگر تحویل نمی‌دهد و فقط تصاویر PNG دارای واترمارک نام و شناسه کاربر را با هدرهای no-store و مسیر وابسته به هویت همان کاربر ارائه می‌کند. کنترل‌های رابط کاربری، چاپ و ذخیره مستقیم را محدود می‌کنند؛ با این حال هیچ نمایشگر تحت وبی نمی‌تواند از عکس‌برداری از صفحه یا ابزارهای ثبت تصویر سیستم‌عامل به‌طور مطلق جلوگیری کند.

حداکثر حجم PDF برابر ۳۵ مگابایت، سقف تعداد صفحات هر سند ۱۰۰ صفحه و مهلت تبدیل هر درخواست سه دقیقه است. فایل‌ها قبل از ذخیره با پسوند و امضای PDF بررسی می‌شوند.
