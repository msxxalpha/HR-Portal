# HR Portal

پورتال جامع منابع انسانی با معماری ASP.NET Core MVC، SQL Server و EF Core.

## تنظیمات محیط سامانه
ماژول تنظیمات محیط شامل اطلاعات عمومی سامانه، ظاهر، منطقه زمانی، تقویم، امنیت ورود، OTP، پیامک، گزارش حقوق و دستمزد و تنظیمات Excel است. مقادیر عملیاتی از پایگاه داده خوانده می‌شوند و تغییر آنها نیازمند سطح دسترسی مدیر سامانه است.

## ساختار اولیه
- اطلاعات پایه کارکنان و ساختار سازمانی
- نسخه‌بندی و بازنگری ساختار سازمانی
- احراز هویت OTP پنج رقمی با اعتبار 120 ثانیه
- تنظیمات سرویس پیامک
- فیش حقوقی SSRS
- تنظیمات محیط سامانه
- Audit Log
