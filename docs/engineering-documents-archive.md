# آرشیو مستندات مهندسی

این ماژول برای نگهداری نسخه‌بندی‌شده مستندات مهندسی و نمایش فقط آخرین نسخه فعال هر سند طراحی شده است.

## نگهداری فایل‌های اصلی PDF در دیتابیس

فایل اصلی هر نسخه در ستون `PdfContent` از نوع `varbinary(max)` در جدول `EngineeringDocumentVersions` ذخیره می‌شود. هش SHA-256 هر فایل نیز در ستون `Sha256` نگهداری می‌شود. هیچ فایل PDF دائمی در پوشه برنامه یا مسیر عمومی وب ذخیره نمی‌شود.

برای تبدیل PDF به تصویر، برنامه محتوای فایل را از SQL Server می‌خواند و فقط در پوشه موقت خصوصی هر درخواست، یک کپی کوتاه‌عمر ایجاد می‌کند تا Poppler آن را پردازش کند. این کپی بلافاصله پس از پایان تبدیل حذف می‌شود؛ تصاویر PNG واترمارک‌شده نیز موقت هستند و حداکثر پس از چهار ساعت پاک می‌شوند.

روی سرور Windows/IIS نسخه سازگار Poppler را نصب کنید و مسیر فایل اجرایی `pdftoppm.exe` را در تنظیمات سرور مشخص کنید:

- کلید پیکربندی: `EngineeringDocuments:PdfToPpmPath`
- یا متغیر محیطی App Pool / سرور: `HRPORTAL_PDFTOPPM_PATH`
- در صورت قرار داشتن `pdftoppm.exe` در PATH، تنظیم جداگانه لازم نیست.

نمونه مقدار تنظیم:

```json
{
  "EngineeringDocuments": {
    "PdfToPpmPath": "C:\\Tools\\poppler\\Library\\bin\\pdftoppm.exe"
  }
}
```

حساب Application Pool فقط برای پوشه `App_Data/EngineeringDocumentTemp` به مجوز Read/Write نیاز دارد. برای فایل‌های PDF اصلی هیچ پوشه ذخیره‌سازی روی سرور لازم نیست. پوشه موقت نباید از Static Files یا مسیر عمومی وب‌سایت سرو شود.

## حدود و ملاحظات امنیتی

نمایشگر، فایل اصلی PDF را در مرورگر تحویل نمی‌دهد و فقط تصاویر PNG دارای واترمارک نام و شناسه کاربر را با هدرهای no-store و مسیر وابسته به هویت همان کاربر ارائه می‌کند. کنترل‌های رابط کاربری، چاپ و ذخیره مستقیم را محدود می‌کنند؛ با این حال هیچ نمایشگر تحت وبی نمی‌تواند از عکس‌برداری از صفحه یا ابزارهای ثبت تصویر سیستم‌عامل به‌طور مطلق جلوگیری کند.

حداکثر حجم PDF برابر ۳۵ مگابایت و سقف تعداد صفحات هر سند ۱۰۰ صفحه است. فایل‌ها قبل از ذخیره با پسوند و امضای PDF بررسی می‌شوند و تبدیل با زمان‌سنج حداکثر سه دقیقه اجرا می‌شود.
