# تطبیق عملکرد ماژول ارزیابی با پروژه مستقل
مبنای مقایسه: `msxxalpha/EmployeePerformanceSystem` / main با `msxxalpha/HR-Portal` / feature/performance-evaluation-module.

## اصول ثابت
- تنها منبع کارکنان، کاربران، سازمان و سطوح دسترسی **HRPortal** است.
- دوره‌های ارزیابی به نسخه ساختار سازمانی HRPortal متصل می‌شوند.
- کپی کنترلرهای Account، Home، Admin و جدول Employees پروژه قبلی ممنوع است.
- صفحات ماژول CSS مجزا دارند و نباید صفحه اول HRPortal را عوض کنند.
- هرگونه تغییر باید روی شاخه مستقل و بعد از تأیید Build، تست SQL Server و رگرسیون با PR به main برسد.

## آزمون‌های لازم پیش از پذیرش
1. یک ارزیاب با ۱۰۰ کارمند: ارزیابی سریع و سپس کاهش امتیاز دو کارمند؛ مجموع‌ها باید صحیح و کسری‌ها پایدار باشند.
2. ارزیاب پایین‌تر و بالادست: حفظ حقوق مشاهده و ویرایش دقیق مطابق ساختار سازمانی.
3. کارمند عادی: فقط گزارش خود را مشاهده کند؛ آزمون تغییر مستقیم query string به شناسه سایر کارکنان.
4. تغییر شرح، سقف یا فعال بودن سؤال نباید ارزیابی تاریخ گذشته را تغییر دهد.
5. حذف دوره: خروج از همه گزارش‌های فعال همراه با امکان بازرسی تاریخچه آرشیو.
6. درج/حذف/انتقال گره‌های سازمانی یا نسخه جدید ساختار، رابطه ارزیاب و تاریخچه دوره قبلی را تغییر ندهد.
7. پس از Deploy روی کپی دیتابیس تولیدی: ورود OTP/رمز، کارکنان، ساختار، فیش حقوقی، حکم و تنظیمات باید همان رفتار سابق را داشته باشند.
8. بررسی بصری RTL، واکنش‌گرایی، باز و بسته‌شدن منو و برابر بودن کارت‌ها و محتواهای Home با main.

**تا اجرای این آزمون‌ها و تکمیل ردیف‌های علامت‌خورده، PR شماره ۳ باید Draft بماند و ادغام با main مجاز نیست.**

## تکمیل بازنگری چندسطحی در همین شاخه
- جدول مستقل `PerformanceEvaluatorChains` برای هر دوره ایجاد شده و برای یک ارزیاب تنها یک بالادست مجاز است.
- موتور ارزیابی برای هر کاربر زنجیره زیرمجموعه را پیمایش می‌کند. مدیر بالادست امکان مشاهده و ویرایش ارزیابی افراد زیرمجموعه را دارد.
- پس از بازنگری مدیر بالادست، ارزیاب پایین‌تر تنها حق مشاهده دارد. علت تغییر و شخص تغییر‌دهنده در تاریخچه ذخیره می‌شود.
- ثبت زنجیره با کنترل چرخه و منع تغییر پس از ثبت اولین ارزیابی دوره انجام می‌شود.
- **محدودیت باقی‌مانده:** زنجیره باید به‌طور صریح توسط مدیر تنظیم شود؛ تعیین خودکار متصدی رئیس/مدیر/معاون از نسخه ساختار سازمانی HRPortal هنوز آماده نیست.
