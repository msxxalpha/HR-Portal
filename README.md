# پورتال جامع منابع انسانی

سامانه وب فارسی و راست‌چین برای مدیریت منابع انسانی شرکت، با تقویم شمسی و معماری ASP.NET Core MVC / SQL Server.

## امکانات پیاده‌سازی‌شده

- داشبورد حرفه‌ای RTL با تم صنعتی سرمه‌ای/خاکستری
- مدیریت کارکنان: افزودن، ویرایش، غیرفعال‌سازی، حذف کنترل‌شده، جستجو، فیلتر و مرتب‌سازی
- ورود و خروجی Excel برای کارکنان
- اطلاعات اجباری کارکنان: شماره پرسنلی، نام، نام خانوادگی، کد ملی، موبایل و جنسیت
- فیلدهای تکمیلی سمت، نوع استخدام، ایمیل، نام پدر و وضعیت
- ساختار سازمانی درختی با کد، عنوان و رتبه مدیریت/ریاست/سرپرستی
- نسخه‌بندی ساختار سازمانی، تاریخ اجرای شمسی، پیش‌نویس، نهایی‌سازی و تاریخچه تغییرات
- جلوگیری از حذف مستقیم گره‌های دارای وابستگی کارکنان یا زیرگره
- انتخاب واحد/اداره/بخش کارکنان از نسخه نهایی ساختار
- احراز هویت بدون رمز عبور با OTP پنج رقمی، اعتبار پیش‌فرض ۱۲۰ ثانیه و محدودیت تلاش
- ارسال OTP از طریق سرویس پیامک قابل پیکربندی
- ثبت رویدادهای مهم در AuditLog
- فیش حقوقی بر پایه RDL/SSRS با پارامتر سال/ماه و شماره پرسنلی کاربر واردشده
- تنظیمات محیط سامانه در تب‌های مستقل: عمومی، ظاهر و برند، امنیت و OTP، پیامک، فیش حقوقی و نگهداری
- تنظیمات ذخیره‌شونده در SQL Server و مقداردهی اولیه خودکار پایگاه داده

## راه‌اندازی

1. در src/HRPortal/appsettings.json مقدار ConnectionStrings:DefaultConnection را مطابق SQL Server محیط خود تنظیم کنید.
2. پروژه را در Visual Studio با .NET 8 اجرا کنید.
3. برنامه در اولین اجرا با EnsureCreated جداول پایه را ایجاد می‌کند.
4. ابتدا از بخش تنظیمات محیط سامانه سرویس پیامک و تنظیمات SSRS را وارد کنید.
5. سپس کارکنان را به صورت دستی یا از Excel وارد کنید.
6. شماره پرسنلی هر کارمند نام کاربری اوست و ورود با OTP انجام می‌شود.

## قالب Excel کارکنان

ستون‌های فایل خروجی سیستم به این ترتیب هستند:
شماره پرسنلی، کد ملی، نام، نام خانوادگی، موبایل، جنسیت، واحد سازمانی، اداره، بخش، سمت، نوع استخدام، ایمیل، نام پدر، وضعیت

در ستون‌های واحد/اداره/بخش، کد ساختار سازمانی وارد می‌شود.

## نکته امنیتی

اطلاعات واقعی سرویس پیامک و سایر کلیدهای محرمانه نباید در GitHub Commit شوند. در محیط عملیاتی آن‌ها را در تنظیمات امن محیط اجرا یا Secret Manager نگهداری کنید.

## SSRS

سامانه URL گزارش را با پارامترهای تنظیم‌شده می‌سازد. برای نمایش داخل iframe، تنظیمات SSRS و سیاست‌های مرورگر/سرور گزارش باید اجازه نمایش در چارچوب را بدهند؛ در غیر این صورت باید از روش proxy/render سمت سرور استفاده شود.


### ارتقای پایگاه داده در این نسخه

برای اینکه اجرای اولیه‌ای که قبلاً با نسخه پایه انجام شده از بین نرود، DatabaseInitializer علاوه بر EnsureCreated، جداول و ستون‌های جدید موردنیاز این نسخه را برای دیتابیس HRPortal موجود ایجاد/تکمیل می‌کند. برای محیط عملیاتی نهایی، تبدیل این سازوکار به EF Core Migrations توصیه می‌شود.
